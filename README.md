# 🧑‍💻 Portfolio — Daniel Bafulwa

Site portfolio personnel de **Daniel Bafulwa**, développeur Django (Python).

## Déploiement Netlify (1 clic)
1. Connectez-vous sur [netlify.com](https://app.netlify.com) avec votre compte GitHub.
2. **Add new site → Import an existing project**.
3. Sélectionnez le dépôt `portfolio` puis **Deploy**.
4. Le site est en ligne sur `https://<nom>.netlify.app` (personnalisable dans **Domain settings**).

## Local
```bash
python3 -m http.server 8000
# ou simplement ouvrir index.html
```
